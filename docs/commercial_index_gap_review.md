# HBM 테마 지수 - 상용지수 대비 개선 진단 (검토본)

기준일: 2026-07-28
비교 목적: 방법론 채택이 아니라 패시브 지수의 투자가능성·비용·집중도 점검

## 1. 현재 판정

- 벤치마크 후보는 국내 반도체 섹터 PR인 `KRX 반도체`, 보조 계열은
  `KRX 반도체 TR`이다.
- `data/benchmark.yaml`은 실제 코드와 위원회 계보가 비어 있으므로
  `PROVISIONAL`이다. 공식 상관계수·추적오차에는 아직 사용할 수 없다.
- 업로드된 215행 판정 CSV는 원천 XLSX의 `admin_issue` 미확인을 모두
  `False`로 바꾼 흔적이 있어 공식 FINAL 원장으로 채택하지 않는다.
  관리종목 이력과 한솔케미칼 FY2020 감사의견의 공식 근거를 확인한 뒤
  원천자료에서 다시 생성한다.

리밸런싱별 `|목표비중-드리프트비중|`, ADV, 참여율, 예상 소요일수로 판단한다.

## 3. 상용상품 수치의 사용 범위

- 개별 최소비중 0.5%와 95% 복제 기준은 상용상품의 참고 규칙이다.
  우리 지수에 자동 편입하지 않고 민감도·상품화 검토에만 사용한다.
- 외부 ETF의 연간 총비용 0.6641%는 그 상품의 보수·비용이다.
  우리 지수의 비용 가정으로 사용하지 않는다.
- 공식 비용 분석은 백테스트 엔진의 드리프트 반영 편도 회전율에
  사전 정의한 편도 비용률을 곱한 0/10/30/50bp 민감도 표로 보고한다.
  외부 ETF 총비용은 별도 스트레스 시나리오로만 병기한다.

## 4. 이미 확정된 규칙

- 핵심군 신규/유지: 30% / 27%
- 위성군 신규/유지: 70% / 67%
- 하드 탈락에는 버퍼 미적용
- 수시편출은 원칙적으로 무대체
- 구성종목 5개 미만일 때만 긴급심사 예외

따라서 `30/25` 버퍼나 예비종목 제도는 개선안으로 다시 제안하지 않는다.
규칙 변경이 필요하면 방법론 개정 절차를 거친다.

## 5. 초기 희소 구간

원장의 `committee_ok` 개수는 실제 편입 이력의 근사치일 뿐이다. 이를 공식
구성종목 수로 단정하지 않는다. 다만 2019~2022년 적격 후보가 매우 적었던
사실은 성과 해석에 중요한 위험이다.

임계값 완화나 광의 반도체 강제 편입은 테마 순수성을 훼손하므로 도입하지
않는다. 실데이터 스냅샷으로 실제 구성 이력을 재생한 뒤 희소 구간을
별도 라벨링하고 집중도·성과기여를 공시한다.

## 6. 실행 순서

1. 관리종목 이력과 감사의견 미확인 건을 공식 자료로 보완한다.
2. strict 모드로 `data/verdict_ledger.csv`를 다시 생성한다.
3. KRX 코드·이름·시계열을 확인하고 위원회 확정일·결의 근거를 기록한다.
4. PR은 PR 벤치마크, TR은 TR 벤치마크로 각각 백테스트한다.
5. 리밸런싱별 집중도·ADV 용량·회전율 비용·추적오차를 보고한다.

판정값과 지표는 방법론 검증용이며 특정 종목 투자 권유가 아니다.
