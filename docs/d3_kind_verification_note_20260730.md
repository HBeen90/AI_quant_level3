## 2. 판정

2020-01-01~2026-07-30 구간에서 후보 33종목의 KIND 시장조치 0350(관리종목)
지정·해제 이력은 미발견이며, 백테스트 `--exclusions`에 추가할 관리종목
수시편출 이벤트는 **0건**이다. 이는 조회 범위·공식 분류코드에 한정된
결론이라는 원 보고서의 스코프 문구를 그대로 유지한다.

부수 확인: 구성종목의 가격 결측 0(백테스트 커버리지)과 결합하면, D3의 다른
두 범주(상장폐지·장기 거래정지)도 구성종목에 한해 부존재가 교차 확인된다.
구성종목 간 합병 이벤트는 편입 이력 8종목이 전 구간 존속했으므로 해당 없음.

## 3. 잔여 항목 2건

1. **human_signoff**: `run_manifest.json`의 `human_signoff: null`에 승인자·
   일자를 기입한다 (자동 조사·독립 검증 완료 상태이므로 승인 절차만 남음).
2. **범위 결정 1건**: 본 조사는 0350(관리종목)만 커버한다.
   **투자주의환기종목**은 기초 유니버스 필터 조건(신규 편입 차단)이지만
   수시편출 사유는 아니므로 백테스트 이벤트에는 영향이 없다 — 다만 유니버스
   필터 완전성 관점의 이력 확인을 추가할지(별도 분류코드 조회) 승인 시
   함께 결정한다.
