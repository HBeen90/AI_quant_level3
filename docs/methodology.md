# HBM 반도체 테마 지수 (HBM Semiconductor Theme Index)

> 국내 상장 기업 중 HBM(High Bandwidth Memory) 밸류체인에 실질적으로 노출된 종목을 규칙 기반(rules-based)으로 선별하여 산출하는 커스텀 인덱스

- **기준일**: 2020년 6월 15일 (SK하이닉스 HBM2E 양산 시점 반영)
- **기준지수**: 1,000.00
- **구성종목**: 규칙 기반 가변 — 앵커·핵심·위성 3군, 종목 수는 산출 시점에
  규칙이 정한다 (고정 정원 폐지, 2026-07-23 개정 — 2장 참조).
  2026-07-23 확정 구성은 7종목.
- **기준일 산출 근거**: 기준일 2020-06-15는 3장 정기변경일 조문(6월 선물·옵션
  만기일 익주 첫 영업일)의 산출값과 일치한다 — 별도 상수가 아니라 조문의 결과다.
- **리밸런싱**: 반기 1회 (연 2회 정기변경)
- **작성**: 4조 임효빈, 노민수, 김소연, 김인서
- **참고**: 본 방법론은 FnGuide 5G Theme Index Methodology Book(2019)의 구조를 템플릿으로 준용

## 1. 지수 소개 및 종목 산출

본 지수는 유가증권시장 및 코스닥시장에 상장된 기업 중, HBM 밸류체인에 실질적으로 노출된 종목을 규칙 기반으로 선별하여 지수화하는 것을 목적으로 한다.

HBM 밸류체인의 구성:

- 메모리 제조 (HBM 생산)
- 후공정·패키징 (TC 본딩 · TSV · 하이브리드본딩)
- 테스트·검사
- 소재·부품
- HBM 칩 생산을 위한 반도체 전공정 장비·소재, 설계 IP

본 지수는 후공정 중심에 국한하지 않고, HBM 칩 제조에 관여하는 **전공정 장비·소재 기업까지 유니버스를 확장**한다.

### 지수 산출 프로세스

```
① 지수 유니버스 확정 → ② 필터 요건 적용 → ③ 포트폴리오 편입 종목 선정 → ④ 최종 비중 결정
```

### 기초 유니버스 필터 (DART에서 수집)

**공통 기준**

| 구분 | 제외 요건 |
|---|---|
| 시장 조치 | 관리종목·투자주의환기종목 지정 또는 상장폐지 확정 종목 |
| 상품 유형 | 선박투자회사, 인프라투자회사, 해외주(외국 기업), REITs, ETF, ETN |
| 상장 기간 | 평가일 기준 상장 후 3개월 미만 (단, 시가총액 50위 이내 종목은 편입 가능) |
| SPAC | 기업인수목적회사 |
| 유동성 | 유동비율(Free Float Rate) 10% 미만 |
| 기타 | 구성종목으로 적합하지 않다고 판단되는 종목 |

**재무건전성 기준**

- 시가총액 350억원 미만 종목 제외
- 직전 60영업일 평균 거래대금 10억원 미만 종목 제외

## 2. 포트폴리오 편입 종목 선정

DART 전자공시의 세그먼트·제품별 매출과 IR 자료로 각 후보의 HBM 매출 노출도를 실측한다.

### 테마 판정 규칙 (정량, 매출 노출도 기준)

| 규칙 | 군 | 판정 기준 |
|---|---|---|
| 규칙 1 | **앵커군** | 메모리 제조, 필수 편입 |
| 규칙 2 | **핵심군** | HBM 밸류체인 매출이 전사매출의 30% 이상 (매출 노출도 정공법) |
| 규칙 3 | **위성군** | 밸류체인에서 칩 제조에 관여하나 HBM 귀속 매출 분리가 어려운 전공정 장비·소재 기업 |

### 편입 종목 및 비중 산정

- **최종 구성 — 규칙 기반 가변 편입 (2026-07-23 개정)**: 고정 정원을 폐지하고
  판정 규칙(규칙 1·2·3) 통과 종목 전원을 편입한다. 종목 수는 산출 시점에
  규칙이 정하며 사전에 정하지 않는다. 잡성 유입은 기초 유니버스 필터가,
  과도한 확대는 편입 임계값이, 쏠림은 개별·합계 비중 상한이 통제한다.
  구성종목 수가 5 미만이 되어도 잔여 종목으로 산출을 지속하고 긴급
  재심사를 개시·공표한다(하단 수시변경 조항 참조).
- **비중 배분**: 앵커군 40% 고정, 핵심군 + 위성군 60%

```
w(비앵커 i) = 0.60 × 유동시총(i) / Σ(비앵커 유동시총)
```

## 3. 리밸런싱 및 수시변경 처리 방식

### 정기변경 (반기 1회)

- **종목 선정일**: 매년 5월, 11월 말 마지막 영업일
- **정기변경일**: 6월, 12월 선물·옵션 만기일 익주 첫 영업일 (연 2회, 반기 주기)
- **성과 보고**: 누적수익률 · 연환산수익률 · 변동성 · 최대낙폭(MDD) ·
  연율화 회전율 · 기존 반도체 지수 대비 상관계수를 백테스트로 산출하여
  제시한다(특정 수치를 사전에 확정하지 않는다 — 측정 결과로 보고).

### 수시변경 및 처리 방식

- 매월 마지막 영업일(D) 종가 기준 개별 종목 비중이 **30%를 초과**하는 경우, 25% 초과분을 다른 종목에 비중 비율로 배분하여 조정한다.
- 상장폐지 · 관리종목 지정 · 구성종목 간 합병 등의 이벤트 발생 시 해당
  종목은 공지 후 D+2에 편출하고 대체 편입 없이 잔여 종목으로 운영한다.
  별도 IIF 재배분은 수행하지 않고 기준시가총액(제수)을 조정하며, 그 결과
  잔여 종목의 상대비중은 기계적으로 상승한다. 정원제 폐지에 따라 예비종목 ·
  차순위 충원 제도는 두지 않는다.
- **구성종목 5 미만 시 처리 (2026-07-23 개정)**: 편출 결과 구성종목 수가
  5 미만이 되는 경우에도 잔여 종목으로 산출을 지속하며, 즉시 긴급 재심사를
  개시하고 공표한다. 긴급 심사는 결원 발생일까지 공개된 최신 확정자료(PIT)로
  수행하고, 새로 편입 요건을 충족한 종목이 확인되면 심사 결과 공표일(A)
  기준 A+2 거래일에 편입한다(무대체 원칙의 유일한 예외 — 하한 회복 목적
  한정). 충족 종목이 없으면 하한 미달 상태로 산출을 계속한다. 미해소 상태가
  60영업일(팀 운영안)을 초과하면 7.3 방법론 종료 절차로 이관하며, 종료
  결정일 · 사전 통지기간 · 최종 산출일은 이관 시 위원회가 결정론적으로
  확정·공표한다.
- **거래정지 종목의 가격 (2026-07-23 확정)**: 거래소가 거래정지를 확인한
  기간에 한하여 해당 종목의 가격은 최종 체결가를 유지하며, 거래 재개 시
  시장가격으로 복귀한다. 거래정지로 확인되지 않은 가격 결측은 임의로
  보정하지 않는다. 상장폐지·파산 편출가격은 ① 정리매매 종가 → ② 거래소
  제공 평가가격 또는 합병조건가 → ③ 최소가격 0.0001원 순으로 결정한다(v8 승계 - 가치 미확정 종목의 완전 소멸 단정과 0원 나눗셈 엣지를 피하는 보수적 처리).
- **구성종목 간 합병 (2026-07-23 확정)**: 피합병(소멸) 종목은 수시편출
  절차(공지 후 D+2, 무대체)로 편출하고 존속 종목은 유지한다. 교환주식
  배정·주식수 증가는 4장 기준시가총액(제수) 수정으로 반영한다. 현금합병
  또는 거래정지로 시장가격이 없는 경우 거래조건가를 사용한다. 합병 편출이
  정기변경일과 겹치면 편출을 선반영한 최종 구성 이벤트 하나로 원자 처리한다.

### 회전율 관리

- **버퍼룰(회전율 억제) — 임계값 히스테리시스 (2026-07-23 개정)**: 정원 폐지에
  따라 순위 버퍼를 임계값 히스테리시스로 대체한다. 신규 편입은 판정
  임계값(핵심 매출 노출도 30% · 위성 메모리향 비중 70%)을 충족할 때만
  이루어지고, 기존 구성종목은 유지 임계값(핵심 27% · 위성 67%) 이상이면
  편입을 유지한다. 임계값 경계에서의 반복 편출입을 억제하여 매매비용과
  추종오차를 낮춘다. 사전 스크린 탈락 · 자료 불충분 · HBM 공정요건 상실 등
  자격 상실 종목은 버퍼 적용 없이 공지 후 D+2에 편출한다(하드 탈락 우선).
  유지 임계값 27%/67%는 현행 운영값으로 확정 적용하며, 정기변경 회차별로
  재량 조정하지 않는다. 최소 2회차의 실측 PIT 데이터가 축적된 뒤 비앵커
  테마 적합도 모니터링 지표와 민감도 분석을 함께 검토하고, 변경이 필요하면
  방법론 개정 절차(7.3)로만 재상정한다.
- **비앵커 테마 적합도 모니터링**: 확정 비중 기준으로
  `[Σ(핵심 비중×매출 노출도)+Σ(위성 비중×메모리향 비율)]
  ÷ Σ(핵심·위성 비중)`을 산출한다. 즉 앵커를 제외한 바스켓 안에서의
  비중가중 평균이며, 앵커 비중 변화가 점수를 기계적으로 누르지 않는다.
  35%는 출범 점수 44.05%의 80%로 둔 운영 참고선이며, 미달하더라도 편출,
  버퍼 해제 또는 비중 변경을 자동 실행하지 않는다. 자동 조치의 도입 여부는
  최소 2회차 실측 축적 후 7.3 개정 절차로 별도 상정한다. 백테스트 러너는
  이를 `theme_relevance.csv`로 별도 출력한다.
- **군 이동과 버퍼 적용 (2026-07-23 확정)**: 파트2 심사에서 기존 구성종목의
  군이 재분류된 경우, 현재 구성종목 지위를 인정하여 이동한 군의 유지
  임계값을 적용한다. 기존 구성원 지위는 군 단위가 아니라 종목 단위로
  인정한다. 군 재분류는 파트2 판정 규칙(규칙 0 > A > C, 하드 요건 완화
  없음)의 산출이며, 회전율 관리 규정은 기존 구성종목에 한해 수치 임계값을
  유지 임계값으로 치환해 적용할 뿐이다. 군 이동은 편출입이 아니라 정기변경
  비중 조정으로 처리하며, 회전율은 비중 변화분으로만 계상한다.
- **발표·적용 시차**: 구성·비중은 개편일(정기변경일 2영업일 전) 종가로 확정·사전 공표하고 정기변경일 종가에 적용한다. → 지수 추종 상품의 사전 매매 준비로 추종오차·시장충격 완화

## 4. 구성종목 및 지수산출

### 지수 산식

```
I(t) = ( M(t) / B(t) ) × 1,000.00

M(t) = Σ IIF(i) × FF(i) × S(i,t) × P(i,t)    (i = 전체 구성종목)
```

| 기호 | 의미 |
|---|---|
| `I(t)` | t시점 지수 (기준일 또는 직전 정기변경일 = 1,000.00) |
| `M(t)` | 비교시가총액 |
| `B(t)` | 기준시가총액 |
| `IIF(i)` | 지수포함가중치 — 앵커 고정비중·실링·위성군 상한을 반영한 캡 조정계수 |
| `FF(i)` | 종목 i의 유동주식비율 |
| `S(i,t)` | 종목 i의 상장주식수 |
| `P(i,t)` | 종목 i의 종가 |

앵커군은 합계 40%, 비앵커 종목은 잔여 60%를 각각 유동시가총액에 비례하여 배분한다.

```
w(앵커 i)   = 0.40 × 유동시총(i) / Σ(앵커 유동시총)
w(비앵커 i) = 0.60 × 유동시총(i) / Σ(비앵커 유동시총)
```

### 기준시가총액(제수) 수정 — 리밸런싱·기업행위

반기 정기변경으로 구성종목·비중이 바뀌거나, 유상증자·액면분할·합병 등 기업행위로 채용 주식수가 변동하는 경우:

```
B(t+1) = B(t) × ( M(t) ± ΔM(t+1) ) / M(t)
```

- `ΔM(t+1)`: 구성·주식수 변동에 따른 비교시가총액 변동액 (= 변동 주식수 × 발행가액 또는 전일종가)

이 수정을 통해 구성 변경·주식수 변동은 지수에 흡수되고, **순수한 주가 변동만 지수에 반영**된다.

## 5. 테마 이력 고지 및 지속성, 한계점

### 테마 이력

- HBM 테마는 2020년 전후로 형성되어 본 방법론 작성 시점 기준 약 5~6년 구간의 데이터를 확보
- 2023년 생성형 AI 확산 이전인 백테스트 구간 전반부(2020~2022)는 테마 응집도와 종목 유동성이 상대적으로 낮음

### 테마의 지속 유효성 근거

- **수요 지속성**: AI 데이터센터 수요
- **밸류체인 다층성**: 제조·후공정·테스트·소재·전공정 장비 등 다층 구조
- **데이터 확보성**: 후보 기업들이 5년 이상 상장 유지

### 한계점

- **종목 집중도 위험**: 앵커군 40% 고정 비중. 2026-07-23 확정 구성에서
  한미반도체 원배분 48.8670%p(비앵커 버킷의 81.445%)로 상한 조정 전
  쏠림이 크며, 개별·합계 상한이 이를 흡수한다.
- **유동성 한계**: 소부장 종목의 낮은 유동성. 지수 추종 시 필요한 매매일수는
  `analysis/capacity_analysis.py`로 AUM 시나리오별 산출한다(참여율 10% 기준).
- **백테스트 데이터 한계 (신설)**: 시점별 판정은 사업보고서 **공시일** 기준
  PIT 원장으로 재구성한다. 회계연도 종료 후 공시까지의 시차 때문에 각 심사
  시점의 판정 근거는 직전 확정 사업연도이며, 이보다 최신인 정보는 사용하지
  않는다(look-ahead 차단 — `analysis/build_pit_snapshots.as_of_ledger`).
- **생존편향 (신설)**: 후보 원장이 현재 상장 종목 위주로 구성되면 과거 구간의
  상장폐지·피합병 종목이 누락되어 성과가 위로 편향된다. 시점별 상장 명단과
  대조하고(`run_backtest.listing_check`), 잔여 편향은 고지한다.
- **유동비율 원천 (신설)**: 현재 DART 사업보고서 기준(최대주주+자기주식 차감)을
  사용한다. KRX 공식 유동비율 확보 시 원천을 단일화하고 재산출한다.
- **유지 임계값 (신설)**: 핵심 27% · 위성 67%는 현행 확정 운영값이다.
  최소 2회차 실측 축적 후에도 방법론 개정 절차(7.3)로만 변경한다
  (회차별 재량 조정 금지).
