# 생존편향 조사 메모 — "당시 자격이었으나 지금 없는 종목"

작성: 2026-07-30 · 파트3 (백테스트 완성 절차 5단계의 사람-조사 부분)
상태: 1차 조사 완료 · D3(수시변경 이벤트 조사, KIND 목록 대조)와 병합 마감 예정

## 1. 조사 구조

생존편향 점검은 두 방향이다.

1. **현 후보 33종목이 과거에 살아있었는가** — 기계 확인 완료.
   가격 패널(2020-06-15~2026-07-23, 1,498일×33종목) 결측 0 →
   후보 전원이 전 구간 상장·거래 상태였다. 상장폐지·장기 거래정지로 인한
   가격 공백 없음.
2. **과거에 자격이었으나 현재 없어서 후보 리스트에 아예 못 들어온 종목이
   있는가** — 코드가 못 찾는 부분. 아래 사람-조사.

## 2. 조사 방법 (2026-07-30 웹 조사)

검색 축: 반도체 장비·소재 상장폐지 목록(2020~2026), 후공정·패키징·테스트
기업 피합병/흡수합병, 감사의견 거절 반도체 기업, 개별 후보 기업명 검증.
전수 열거가 아닌 표적 조사이며, 완결은 KIND 상장폐지 목록 전수 대조(§5)로 한다.

## 3. 발견 — 검토 대상 1건

**에이티세미콘 (089530)** — 반도체 테스트(메모리 중심) 기업.
FY2023 감사의견 거절 → 매매거래정지 → **2024-08 상장폐지** (KIND 공시
확인: 상장폐지 2024-08-26 정리매매 안내). 백테스트 구간 내 소멸이며,
메모리향 테스트라는 사업 프로필상 **위성군 후보 자격을 검토했어야 할
대상**이다.

**판정 결과 (2026-07-30 갱신): 편입 자격 아님(전 기간) — 잠정, 파트2 추인
대기.** 근거와 추인 체크박스는
`docs/judgment_record_322310_atsemicon_20260730.md` 판정 2를 정본으로
본다. 요지: 레거시 메모리 패키징·테스트 OSAT로 HBM 고유공정(TSV·TC본딩)
관여의 공개 근거가 전무 → 위성 결합 요건(process_confirmed) 미충족 →
전 기간 미편입. 2023 이후는 감사의견 거절 하드 탈락으로 자격 논의 자체가
불성립. **따라서 이 종목의 부재는 백테스트 성과를 위로 편향시키지 않는다.**

## 4. 현재 말할 수 있는 문장 (한계점 반영용)

> 후보 33종목은 백테스트 전 구간에서 가격 결측 없이 거래됐다. 별도로
> 2020~2026년 사이 상장폐지된 메모리향 반도체 기업 1건(에이티세미콘,
> 2024-08 상폐)을 식별해 자격을 판정한 결과 위성 결합 요건(HBM 고유공정
> 확인) 미충족으로 전 기간 편입 자격이 아니었음을 확인했다(잠정, 파트2
> 추인 대기) — 동 종목의 부재는 성과를 편향시키지 않는다. 다만 후보
> 리스트가 2026년 시점 지식으로 구성된 데 따른 **상향 가능성이 큰
> 선택·생존편향**의 잔여 가능성은 일반 한계로 고지한다(방향은 일반적으로
> 위쪽이나 수학적으로 항상 보장되지는 않는다).

## 5. 잔여 절차

1. D3 조사 시 KIND 상장폐지 종목 목록(2020~2026)에서 업종=반도체 관련을
   전수 추출해 §3 표를 확장한다 (로컬 KIND 조회 — 표적 웹 조사의 한계 보완).
2. 에이티세미콘 미니 판정(파트2) 결과를 본 메모에 추가 기록한다.
3. `listing_check()`(pykrx 상장명단 대조)를 확정 재실행 시 함께 돌려
   기계 확인을 재봉인한다.
4. 향후에는 후보발굴 원장(`candidate_discovery`)이 심사시점마다 전시장을
   스캔하므로, 이 편향은 운영 개시 이후 구간에서 구조적으로 소멸한다 —
   백테스트 과거 구간 한정 고지로 남는다.
