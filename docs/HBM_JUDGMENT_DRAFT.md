## 아직 확정되지 않은 것

이번 자료는 **한 시점의 확정 단면**이지 2019-2025 역사적 PIT 원장이 아니다.

- 종목별 원천 DART URL과 개별 공개일
- 사업연도별 HBM 노출도·메모리향 비중·공정 확인
- 당시 관리종목 상태와 유동비율
- 과거 상장폐지·피합병 종목을 포함한 시점별 후보 집합

따라서 2026-07-23 값을 과거 심사일에 복사하지 않는다. 지수 시계열,
CAGR·변동성·MDD·회전율·벤치마크 상관계수도 아직 실측값으로 해제하지 않는다.
