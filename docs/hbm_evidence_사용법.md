# hbm_evidence.py 사용법 — HBM 판정 근거 자동 수집 도구

작성: 노민수

## 이게 뭐 하는 도구인가

편입 판정에 필요한 값 중 **세 가지는 자동으로 못 구한다** — 기업이 별도 공시하지 않아서다.

| 값 | 쓰이는 규칙 |
|---|---|
| HBM양산 (True/False) | 규칙 0 (앵커군) |
| HBM노출도 (HBM 밸류체인 매출 ÷ 전사 매출) | 규칙 A (핵심군) |
| 메모리향비중 (메모리 반도체용 매출 ÷ 전사 매출) | 규칙 C① (위성군) |

사람이 사업보고서를 읽고 판단해야 하는데, **자료를 찾아 여는 시간이 대부분**이다.
이 도구는 그 찾는 시간을 없앤다. 종목코드만 넣으면:

1. 최신 사업보고서를 DART에서 내려받고
2. 「매출 및 수주상황」의 제품별 매출 표를 뽑고
3. HBM·TSV·하이브리드본딩 등 키워드가 나온 문장을 전부 모으고
4. 공급계약(수주) 공시 목록, 감사의견, 관리종목 여부, 유상증자·CB 공시, IR 페이지 링크까지 찾아서
5. 종목별 **판정 카드(.md)** 한 장으로 만들어 준다

→ **카드만 읽고 숫자만 적으면 끝.** 종목당 판단 시간 약 10~20분.

## 설치 (처음 한 번)

```
pip install pandas opendartreader python-dotenv requests pykrx finance-datareader
```

## DART API 키 설정 (처음 한 번)

1. https://opendart.fss.or.kr 에서 무료 API 키 발급 (즉시 발급됨)
2. 이 파일과 같은 폴더에 `.env` 파일을 만들고 한 줄 작성:

```
DART_API_KEY=발급받은_키
```

> ⚠️ **`.env`는 절대 커밋하지 말 것.** 이 레포는 public이라 키가 올라가면 전 세계에 공개된다.
> (같은 폴더의 `.gitignore`가 막아주지만, 각자 주의할 것)

## 실행

```
# 방법 1: 종목코드 직접 입력 (쉼표 구분)
python hbm_evidence.py --codes 042700,005930,000660

# 방법 2: CSV로 입력 (컬럼: 코드 — 종목명은 있으면 쓰고 없으면 자동 조회)
python hbm_evidence.py --input 후보리스트.csv

# 입력 없이 실행하면 데모 3종목으로 동작
python hbm_evidence.py
```

과거 사업연도 카드에는 `--fiscal-year`를 반드시 지정합니다. 이 경로는
DART 목록을 `final=False`로 조회해 원본·정정공시를 모두 받은 뒤
접수일·접수번호 순 최초 사업보고서를 선택합니다.

종목코드는 **6자리 문자열**(예: `005930`)로. 엑셀에서 저장하면 앞자리 0이 날아가므로
(005930 → 5930) CSV는 메모장이나 구글시트로 만드는 것을 권한다.

## 결과물

```
evidence/
├─ 005930_삼성전자.md      ← 종목별 판정 카드
├─ 042700_한미반도체.md
└─ 판정입력_템플릿.csv      ← 카드 읽고 여기만 채우면 됨
```

**판정 카드 구성**: 판정 입력값 표(빈칸) → 자동 채움된 사전 스크린(감사의견·관리종목) →
IR 바로가기 링크 → 제품별 매출 표 → HBM 언급 문장 → 고유공정 언급 → 메모리/비메모리 언급 →
공급계약 공시 → 감사의견 근거 → 희석 이벤트 공시 → DART 원문 링크

**판정입력_템플릿.csv**: 감사의견·관리종목은 자동으로 채워져 있고,
`유형 · HBM양산 · HBM노출도 · 메모리향비중 · HBM공정확인 · 위원회확인` 6칸만 손으로 채운다.

## 판단 요령

- 카드 2번 "HBM 언급 문장"만으로 노출도 판단이 서면 IR은 열지 않아도 된다
- 애매하면 카드 상단의 IR 링크를 눌러 실적발표 자료를 본다 (IR 자료는 DART에 없음)
- **노출도 산정이 곤란하면 억지로 추정하지 않고 제외한다** (규칙 A의 보수 원칙)

## 주의

- `evidence/` 폴더에는 사업보고서 원문 발췌가 대량 포함되므로 **레포에 커밋하지 말 것**
  (`.gitignore`에 등록돼 있음). 팀에 공유하는 것은 카드가 아니라 **산정한 값**이다.
- DART API는 일일 호출 한도(20,000건)가 있으나 종목당 몇 건 수준이라 문제되지 않는다.
- `annual_report()` 호출에 `final=False`가 없는 구 수집기는 사용하지 않는다.
  정정공시가 존재하는 종목·연도에서 최초 공개시점이 뒤로 이동할 수 있다.
