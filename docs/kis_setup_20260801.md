# KIS(한국투자증권) Open API 연결 — 설정·검증 절차

- 작성: 2026-08-01 · 배경: KRX Data Marketplace 접근 제한(07-31 통보)
- 코드: `analysis/kis_client.py` · `analysis/fetch_prices_kis.py`
- 테스트: `tests/test_kis_client.py` 9건 (네트워크 불요)
- **엔진 코드 변경 0** — KIS 산출물을 기존 캐시 형식으로 써서
  `--prices-cache` 로 먹인다. 확정 매니페스트의 '코드 무변경' 조건 유지.

## 1. 키 발급 (1회)

1. https://apiportal.koreainvestment.com (KIS Developers) 가입
   — 한국투자증권 계좌 필요. 없으면 비대면 개설(당일~1일).
2. [API 신청] → 실전투자 앱 등록 → **APP Key / APP Secret** 발급.
   시세 조회는 실전 도메인에서 바로 된다(주문 권한과 무관).
3. 키는 파일·코드·커밋에 넣지 않는다. 세션 환경변수로만 준다.

## 2. 키 주입 (PowerShell · 세션 한정)

```powershell
$k = Get-Credential -UserName "KIS_APP_KEY" -Message "APP Key를 비밀번호 칸에"
$s = Get-Credential -UserName "KIS_APP_SECRET" -Message "APP Secret을 비밀번호 칸에"
$env:KIS_APP_KEY    = $k.GetNetworkCredential().Password
$env:KIS_APP_SECRET = $s.GetNetworkCredential().Password
```

## 3. 연결 점검 (스모크 · 2종목 7개월)

```powershell
python analysis\fetch_prices_kis.py --tickers 005930,000660 `
    --start 20260101 --end 20260723 --out out\px_kis_smoke.csv
```

기대 출력: `[OK] KIS 토큰 확보` → `[저장] ... (약 135일 x 2종목)`.
토큰은 `~\.kis_token.json` 에 캐시되며 24시간 재사용된다(발급 빈도
제한이 있으므로 이 파일을 지우고 반복 실행하지 말 것).

## 4. 본 수집 + 교차검증 (핵심 게이트)

```powershell
python analysis\fetch_prices_kis.py --snapshots data\snapshots `
    --start 20200601 --end 20260723 `
    --out out\px_kis.csv --value-out out\value_kis.csv `
    --compare out\px.csv
```

- `--compare out\px.csv` 가 **재현성 판정**이다. 수정주가 보정 방식이
  기관마다 달라 pykrx 패널과 완전 일치가 보장되지 않는다.
  - 허용오차(기본 1e-6) 내 전수 일치 → 이 패널로 FINAL 재현 가능.
  - 초과 셀 존재 → FAIL 로 중단 + `out\px_kis_crosscheck.csv` 에 상세.
    이 경우 **FINAL 수치(레벨 20,881.52) 재현을 주장하지 말고**, 차이의
    성격(반올림·분할 보정)을 확인해 위원회 보고 사항으로 올린다.
- `--value-out` 은 일별 거래대금 패널이다(ADV60 산출용).

## 5. 엔진 연결

교차검증 통과 시:

```powershell
python analysis\run_backtest.py ... --prices-cache out\px_kis.csv
```

캐시 분기가 읽으므로 엔진은 KIS 의 존재를 모른다. 커버리지·중복·기간
검증(fail-closed)은 엔진 쪽 기존 코드가 계속 수행한다.

## 6. 범위 한계 — 시가총액

KIS 는 **상장주식수 이력을 주지 않는다.** 현재 주식수 × 과거 종가는
증자·분할 구간에서 틀리므로 과거 시총을 KIS 로 만들지 않는다.
스냅샷 재생성(시총 350억·ADV60 10억 스크린)에 필요한 과거 시총은:

| 경로 | 성격 | 상태 |
|---|---|---|
| 공공데이터포털 금융위 주식시세정보 (`mrktTotAmt`) | 공식 API · 자동화 가능 | 다음 작업 후보 |
| KRX 정보데이터시스템 화면 다운로드 | 차단 안내문이 명시 허용한 수동 경로 | 즉시 가능 |

ADV60 은 본 수집의 `value_kis.csv` 로 충분하다.

## 7. 하지 않는 것

- KRX Data Marketplace 재접속·우회 시도 — 차단이 연장될 뿐이다.
- 부분 산출물 저장 — 수집이 중단되면 아무것도 쓰지 않는다(fail-closed).
- 키 하드코딩·커밋.
