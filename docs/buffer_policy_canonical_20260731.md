## 0. 왜 이 문서가 필요한가

버퍼 민감도 수치가 프로젝트 안에 **최소 네 벌** 돌아다닌다. 서로 다른 세대의
산출물이 문서·대시보드·발표자료에 남아 있고, 어느 것이 정본인지 적힌 곳이
없었다.

| 출처 | 회전율 (none→wide) | 상태 |
|---|---|---|
| 초기 데모 | 32% → 24% | **폐기** |
| `presentation_qa.md` | 52.5% → 39.7% (캡 7회→2회) | **폐기** |
| 단일 seed CSV | 36.2 / 33.0 / 24.4 / 20.1 | **폐기** (seed 1개) |
| 대시보드 화면 | 48.5 / 38.2 / 24.6 / 18.2 | **폐기** |
| **다중 seed 중앙값** | **37.7 / 36.6 / 26.8 / 20.4** | **정본** |

그리고 이보다 중요한 사실이 하나 더 있다 — **실측에서는 네 정책이 소수점
끝까지 같다.** 어느 합성 수치를 인용하든 `policy_comparison.csv`를 여는
순간 "그럼 실측은요?"가 따라온다. 그 답까지 함께 준비돼야 한다.

## 1. 정본 — 합성 민감도 (다중 seed 11개)

`analysis/sensitivity_v2.py`, seed 11개, 연율화 편도 회전율.

| 정책 | 유지 임계 | 중앙값 | 평균 | 최소 | 최대 | none 대비 |
|---|---|---:|---:|---:|---:|---:|
| none | 30% / 70% | **37.7%** | 37.5% | 34.1% | 40.1% | — |
| narrow | 29% / 69% | **36.6%** | 35.6% | 30.6% | 39.1% | −3.0% |
| **mid (현행)** | **27% / 67%** | **26.8%** | 26.1% | 22.8% | 28.9% | **−28.8%** |
| wide | 25% / 65% | **20.4%** | 21.1% | 18.2% | 24.5% | −46.0% |

**단일 seed를 인용하지 않는다.** seed 하나만 쓰면 36.2 / 33.0 / 24.4 / 20.1이
나오는데, 이는 seed 간 변동 범위(none 34.1~40.1%) 안의 한 점일 뿐이다.
정책 간 **차이**는 안정적이나 절대 수준은 seed에 의존한다.

**합성 데이터임을 반드시 병기한다.** `sensitivity_v2.py` 자체가 docstring에
"합성이므로 정책 간 차이만 유효"라고 적고 있다.

## 2. 실측 — 네 정책이 동일하다

| 정책 | 연율화 회전율 | 버퍼 발동 | CAGR | MDD |
|---|---:|---:|---:|---:|
| none | 1.3720 | **0** | 64.54% | −45.18% |
| narrow | 1.3720 | **0** | 64.54% | −45.18% |
| mid | 1.3720 | **0** | 64.54% | −45.18% |
| wide | 1.3720 | **0** | 64.54% | −45.18% |

소수점 끝까지 같다. 원인은 편출이 6년간 0건이고, 그 원인은 편입 7종목의
판정값이 전 구간 **단조 비감소**라는 데 있다. 버퍼가 물릴 기회 자체가 없었다.

> **함정.** 한미반도체의 0.80 → 0.60은 하락이 아니다. 위성군일 때는
> 메모리향비중, 핵심군으로 승격한 뒤에는 HBM노출도로 판정하므로 **지표가
> 갈아끼워진 것**이다. 같은 군이 이어진 구간 안에서만 비교해야 한다.

## 3. 규칙은 살아 있다 — 반증 실험

"발동 0건이면 규칙이 죽은 것 아닌가"에 대한 답이다.
`out/backtest/buffer_falsification.csv` — 판정값을 인위적으로 낮춰 본다.

| 충격 | none 발동 | narrow | mid | wide |
|---:|---:|---:|---:|---:|
| 0.0%p | 0 | 0 | 0 | 0 |
| **1.0%p** | **0** | **1** | **1** | **1** |
| 2.0%p | 0 | 0 | 1 | 1 |
| 3.0%p | 0 | 0 | 1 | 1 |
| 5.0%p | 0 | 0 | 0 | 1 |

**1%p 충격만으로 정책이 갈라진다.** none은 끝까지 0건이고 버퍼 정책들은
발동한다. 규칙은 정상 작동하며, 조용했던 것은 표본이다.

## 4. 발표 문장 — 이것만 쓴다

> 27/67은 다중 seed 합성 민감도에서 채택한 현행 운영값입니다. 회전율
> 중앙값이 none 대비 28.8% 낮았습니다. 다만 **표본 구간에서는 편입 종목의
> 판정값이 단조 비감소여서 버퍼가 한 번도 발동하지 않았고, 실측에서는 네
> 정책이 동일합니다.** 1%p 충격 반증 실험에서 정책이 갈라지므로 규칙은
> 살아 있으며, 조용했던 것은 표본입니다.

세 문장이 **한 묶음**이다. 앞만 말하면 실측과 충돌하고, 가운데만 말하면
규칙이 죽은 것처럼 들린다.

### 쓰면 안 되는 문장

- ~~"실측 회전율을 보고 27/67을 골랐다"~~ — 합성이다
- ~~"버퍼가 회전율을 29% 낮췄다"~~ — 실측 효과는 0이다
- ~~단일 seed 수치(36.2 / 24.4 등)~~ — seed 변동 범위 안의 한 점
- ~~폐기된 세대 수치(52.5→39.7, 48.5→18.2 등)~~

않되, 참조하는 문서·화면에서 정본으로 교체한다.

```

buffer_policy_sensitivity_panel.html 의 48.5/38.2/24.6/18.2
```

발표자료 확정 후 다음을 실행해 유출을 점검한다.

```powershell

```
