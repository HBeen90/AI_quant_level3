# index_calc.py 접합 검증 노트 — 소연 → 인서님

대상: `src/index_calc.py` (업로드본은 저장소본과 줄바꿈만 다르고 소스 내용 동일)
결과: **동치성 공동 대조 3/3 통과** — 정기변경과 무대체 수시편출 경로가
허용오차 안에서 일치한다.

## 1. 동치성 공동 대조 결과 (tests/test_index_calc_equivalence.py, 신규)

| 대조 | 내용 | 결과 |
|---|---|---|
| A. 정기변경 | 인서님 IIF+제수 경로(`build_daily_series`) vs 소연 비중 drift 경로(`simulate_index`) — 가변 종목 수(7→6) 2회 리밸런싱, 260일 | **최대 상대차 2.41e-15** |
| B. 수시편출 | 3.4 제수 조정(`adjust_base_market_cap`, ΔM = −편출 종목 기여분) vs 소연 드리프트 후 정규화 이벤트 — 편출일·익일 경로 포함 | **최대 상대차 1.71e-15** |
| C. 어댑터 | 소연 정기 이벤트 → `build_daily_series` 입력 변환 시 일자·종목별 FMC 누락 fail-closed | 통과 |

수치는 실행 환경의 부동소수점 연산 순서에 따라 조금 달라질 수 있으므로
발표에서는 **"최대 상대차 1e-14 미만"**으로 보고한다.

의미: 방법론의 "무대체 편출은 별도 IIF 재배분 없이 제수를 조정하며 잔여
상대비중이 기계적으로 상승한다" 조문이 **양쪽 구현으로 상호 실증**됐다.
인서님 산출기의 3.3 예시(1015.40) 자체 검증도 별도로 통과한다.

검증 범위는 정기변경과 무대체 수시편출이다. 월간 cap·긴급편입·주식교부
합병 경로까지 동치가 증명된 것으로 확대 해석하지 않는다.

## 2. 인계 인터페이스 확정 사항

- `load_constituents` 최소 컬럼(코드·종목명·bucket·weight·ff_market_cap·
  price)은 현재 인계 스키마와 호환된다.
- 실제 산출용 `price`와 `ff_market_cap`은 정기변경 시행일 기준으로 맞추고,
  각 기준일·원천 메타데이터를 함께 보존해야 한다. 선정기준일 값과
  시행일 값을 혼용하지 않는다.
- 정기변경 입력: 소연 이벤트를 `to_reconstitution_events(events,
  fmc_by_date)` 어댑터로 변환해 그대로 넣으면 됩니다(테스트 파일에 포함).
- 무대체 수시편출은 대조 B의 저수준 3.4 제수 조정 경로로 처리한다.
- cap·emergency_fill은 목표비중 재설정이므로 별도 IIF·제수 재설정 접합
  테스트 후 운영 경로를 확정한다. 대조 B는 이 두 이벤트를 보장하지 않는다.

## 3. 소소한 제안 (수정 없이도 동작함 — 다음 정리 때 반영 권장)

1) **헤더 docstring v1 잔존**: "최종 구성종목 12개 (앵커2·핵심7·위성3)"
   → v2 확정(가변 종목 수, 규칙 통과 전원 편입)으로 갱신. `__main__`
   데모의 12종목 예시는 3.3 문서 예시 검증용이므로 유지하되 "구판 예시
   검증용" 주석 한 줄 권장.
2) **build_daily_series 확장 방향**: 현재 정기 이벤트 전용이다. 수시편출
   연결 시 대조 B의 저수준 조합(ΔM 부호: 편출=음수)을 참조한다.
3) **잔여 인계 과제(기존 합의 유지)**: 주식교부 합병의 '최종 목표비중
   이벤트' 생성 — 피합병 편출(ΔM 음수) + 존속회사 주식수 증가(ΔM 양수)
   조합. 이벤트 규격은 기존 그대로면 소연 쪽 simulate_index가 즉시
   소비합니다.
