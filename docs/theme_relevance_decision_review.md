# 비앵커 테마 적합도 모니터링 지표 의결 안건

> 담당: 김소연(버퍼룰·성과지표)
> 목적: 유지 임계값 27%/67%의 사후 검증에 사용할 보조 통제지표를
> 정의하고 자동 조치안의 보류 범위를 확정한다.

## 결론

유지 임계값 27%/67%는 현행 운영값으로 적용한다. 비앵커 테마 적합도
점수와 35%는 **보고용 모니터링 지표와 비구속적 참고선**으로만 채택한다.
35% 미달은 현재 구성 변경, 버퍼 해제 또는 편출을 자동으로 유발하지 않는다.

자동 버퍼 해제와 대안 구성 산출 절차는 최소 2회차의 정기변경 실측 데이터가
축적될 때까지 보류한다. 이후에도 방법론 개정 절차(7.3)를 거친 경우에만
운영 규칙으로 전환할 수 있다.

## 1. 지표 정의

정식 명칭은 **비앵커 테마 적합도 점수**로 한다. 발표에서는 편의상
"테마 순도"라고 부를 수 있으나, 문자 그대로의 HBM 매출 비중은 아니다.

```text
R = Σ(w_i × s_i) / Σw_i,  i ∈ 비앵커

핵심군 s_i = HBM 밸류체인 매출 노출도
위성군 s_i = 메모리향 매출 비중
```

두 군의 `s_i`는 서로 다른 경제적 개념이므로 `R`은 복합 적합도 점수다.
앵커군은 규칙 0 자격 충족 비중을 별도 지표로 보고하고 `R`에서는 제외한다.

산정 계약은 다음과 같이 고정한다.

- 파트2가 선정기준일 현재 공개된 확정자료로 판정한 값만 사용한다(PIT).
- 파트2가 확정한 최종 군을 사용한다.
- 정기변경 목표비중을 캡·재배분 폭포까지 적용한 뒤 산정한다.
- 노출도 또는 메모리향 비중이 결측이면 임의로 0을 넣지 않고 중단한다.
- 비앵커 종목이 없으면 점수는 정의 불능으로 처리하고 긴급심사 절차로 넘긴다.

## 2. 2026-07-23 기준점

공표된 반올림 비중으로 계산한 결과는 다음과 같다.

| 상황 | 점수 |
|---|---:|
| 현 구성 | 44.0517% |
| 테크윙 30% → 27%, 나머지 불변 | 43.1517% |
| 모든 현 구성원이 27%/67% 유지선까지 하락, 현 비중 고정 | 27.4067% |

`27.4067%`는 **현 구성·현 비중 의존 하한**이다. 종목과 군별 비중이
바뀌면 함께 바뀐다. 중간 버퍼 정책의 방법론 전체에 적용되는 보수적 하한은
핵심군만 존재할 수 있다는 점을 고려한 `27.00%`다.

확정 `ff_market_cap` CSV가 아직 없으므로 44.0517%는 공표 반올림 비중
기준값이다. 확정 CSV로 순방향 재현한 뒤 원시 비중 기준 수치로 교체한다.

### 단일 종목 스트레스

다른 종목은 현재 값으로 두고 각 종목 하나만 유지선까지 낮춘 결과다.

| 유지선 도달 종목 | 점수 |
|---|---:|
| 한미반도체 60% → 27% | 34.1517% |
| 테크윙 30% → 27% | 43.1517% |
| 디아이 35% → 27% | 42.3437% |
| 넥스틴 50% → 27% | 39.9960% |
| 와이씨켐 75% → 67% | 43.9703% |

따라서 35% 미만은 경계 종목 여러 개가 누적될 때만 나타나는 상태가 아니다.
현재 구성에서는 비중이 큰 한미반도체의 노출도 하락 하나만으로도 점수가
35% 아래로 내려간다. 모니터링 결과를 해석할 때 이 집중도 영향을 함께
보고해야 한다.

## 3. 35% 모니터링 참고선의 근거와 한계

35%는 통계적으로 최적화된 값이 아니다. 다음과 같은 **팀 보고 가정**으로
투명하게 정의한다.

```text
출범 기준 점수의 80% = 44.0517% × 0.80 = 35.2413%
보고 편의를 위해 35%로 내림
```

즉 출범 시점 대비 약 20% 이상의 상대적 적합도 저하 여부를 보고한다.
이 근거는 재현 가능하지만 학술적으로 유일한 답은 아니며 자동 구성 변경의
근거로 사용하지 않는다. 최소 두 차례의 정기변경 OOS 결과 또는 동일한 PIT
계약의 역사적 스냅샷이 쌓인 뒤 사전 정의한 목적함수 아래에서 재검토한다.
결과를 본 뒤 회차별로 임계값을 바꾸지는 않는다.

## 4. [보류] 자동 대응 규칙 검토안

아래 절차는 실측 데이터 축적 후 재상정할 검토안이며 현재 운영 규칙이
아니다. 채택하는 경우에도 35% 미만은 절대 편입 하한이 아니라 버퍼가
과도한 잔류를 만들었는지 확인하는 트리거로 한정한다.

1. 정상 버퍼(27%/67%)로 선정·비중 산정 후 `R_1`을 계산한다.
2. `R_1 < 35%`이면 그 회차에 한해 유지선도 신규선(30%/70%)으로 두고
   후보 구성과 비중을 한 번만 다시 계산해 `R_2`를 구한다.
3. 대안 구성이 산출 가능하고 `R_2 > R_1`이면 대안 구성을 최종 채택한다.
4. 비앵커 부재 등으로 산출할 수 없거나 `R_2 ≤ R_1`이면 원래 구성을 유지하고
   지수위원회에 예외 사유를 공표한다. 기존 5종목 미만 긴급심사 규정도 함께
   적용한다.
5. 재귀적인 추가 재선정은 하지 않는다. 백테스트에는 최종 구성 이벤트
   하나만 기록해 회전율을 이중 계상하지 않는다.

## 5. [보류] 향후 조문 초안

> **향후 재상정용 비앵커 테마 적합도 경보선.** 정기변경 목표비중 확정 후 비앵커 테마
> 적합도 점수가 35% 미만이면, 해당 회차에 한해 기존 구성종목에도 신규
> 편입 임계값을 적용한 대안 구성을 1회 산출한다. 대안 구성이 산출 가능하고
> 점수가 개선되면 이를 최종 구성으로 채택한다. 대안 구성이 산출 불가능하거나
> 점수가 개선되지 않으면 정상 버퍼 적용 구성을 유지하고 그 사유를
> 지수위원회에 보고·공표한다. 경보선과 유지 임계값은 방법론 개정 절차로만
> 변경한다.

## 6. 발표 수치의 정확한 표현

테크윙 사례는 **실제 시계열 관측값이 아니라 실데이터에 고정한 스트레스
시나리오**다. 테크윙이 반기마다 30%와 29%를 왕복하고 목표비중이 18%라고
가정하면, 버퍼가 없을 때 편출 18% + 재편입 18%로 연간 편도 회전율은
약 36%p다. 왕복비용률 30bp 가정의 비용 드래그는 `36% × 30bp = 10.8bp`다.
중간 버퍼에서는 같은 경로의 구성 변경 회전율이 0이다.

이 수치는 히스테리시스의 필요성을 설명하지만 27%/67%가 최적임을 단독으로
증명하지는 않는다.

## 의결 항목

1. 정식 지표명을 `비앵커 테마 적합도 점수`로 할지
2. 35%를 자동 조치 없는 비구속적 모니터링 참고선으로 승인할지
3. 출범 기준 점수의 80%라는 보고 근거를 승인할지
4. 자동 버퍼 해제와 대안 산출 절차는 최소 2회차 실측 축적 후 재상정할지
5. 27%/67%를 현행 운영값으로 적용하고 방법론 개정 절차로만 재검토할지
