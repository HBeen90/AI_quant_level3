**설정.** 시장구분 **전체**. KOSPI 만 받으면 전종목 시총 순위가 틀어져
상장 3개월 면제 판정이 달라진다.

**조회일자 13개** (방법론이 정한 종목 선정일 ― 5월·11월 말 영업일)

```

2024-05-31  2024-11-29  2025-05-30  2025-11-28
2026-05-29
```

받은 CSV 를 임의 폴더에 모은다. 파일명은 무관하다 ― 다음 단계가 내용으로
날짜를 판정한다.

**열 구성** ― `종목코드 · 종목명 · 시장구분 · 소속부 · 종가 · 대비 · 등락률 ·
시가 · 고가 · 저가 · 거래량 · 거래대금 · 시가총액 · 상장주식수` (CP949)

## 3. KIS 가격·거래대금 패널

`docs/kis_setup_20260801.md` 절차로 앱키를 확보한 뒤 **두 벌**을 받는다.

```powershell
# 수정주가 - 지수 수익률용
python analysis\fetch_prices_kis.py --snapshots data\snapshots `
    --start 20200201 --end 20260723 `
    --out out\px_kis_ext.csv --value-out out\value_kis_ext.csv

# 원주가 - 시총 검증용
python analysis\fetch_prices_kis.py --snapshots data\snapshots `
    --start 20200201 --end 20260723 --unadjusted --out out\px_kis_raw.csv
```

**시작일이 2020-02-01 인 이유.** 첫 선정일(2020-05-29)의 ADV60 은 직전
60거래일(약 2020-02-24 부터)을 요구한다. 2020-06-15 부터 받으면 그 회차
전 종목이 `ADV60<10억` 으로 탈락해 **원인은 데이터 부재인데 규칙 탈락으로
기록**된다.

> **수정주가와 원주가를 섞지 말 것.** 시총 = 주식수 x 종가 인데 수정주가는
> 이후 분할을 소급 반영한 값이라, 과거 주식수와 곱하면 **분할 배수만큼
> 틀린다**(실측: 1:2 분할 종목에서 정확히 −50%).

## 5. 실행

```powershell
# 5-1. 화면 파일의 조회일자 판정 + 이름 부여
python analysis\match_krx_screens.py `
    --screens-in "<받은 폴더>" --prices-raw out\px_kis_raw.csv `
    --out data\market_facts\raw --dry-run
#   13개 전부 '확정' · 일치율 100% 를 확인한 뒤 --dry-run 을 빼고 재실행

# 5-2. 상장일
python analysis\derive_listing_dates.py --snapshots data\snapshots `
    --krx-basic "<전종목 기본정보 파일>" --out data\listing_dates.csv

# 5-3. 시장 팩트 생성 + 교차검증
python analysis\krx_facts_from_screen.py --screens data\market_facts\raw `
    --values out\value_kis_ext.csv --listing-dates data\listing_dates.csv `
    --out data\market_facts --compare data\snapshots

# 5-4. 스냅샷 전량 재생성 (13회차 · 한 커밋 · 부분 재생성 금지)
python analysis\build_pit_snapshots.py --ledger data\verdict_ledger.csv `
    --out data\snapshots --facts-dir data\market_facts `
    --facts-source "KRX all-stock screen download x ledger free_float" `
    --code-commit (git rev-parse HEAD)

# 5-5. 확정 실행
.\run_backtest_final.ps1 -IndexAsof 2026-07-23
```

**5-1 이 자동 판정인 이유.** 다운로드 파일명이 전부 **다운로드 날짜**라
조회일자를 알 수 없다. 종목 수나 대표 종목 가격으로 순서를 추정하면 분할
때문에 어긋난다(실측: 삼성전자 317,000 → 56,200). KIS 원주가 패널과 33종목
종가를 대조해 판정하며, 일치율 미달·모호·중복이면 중단한다.

받은 파일이 우리가 쓴 것과 같은지 확인한다.

```powershell
Get-FileHash <파일> -Algorithm SHA256 | Select-Object -ExpandProperty Hash
```

KRX 화면의 표기 변경. 그 경우 해시 대신 **§7 의 값 대조**로 확인한다.
